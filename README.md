# Smart Study Planner API

A RESTful backend API built using Node.js, Express, and MongoDB
to manage study tasks efficiently.

## Features
- Add tasks
- View tasks
- Delete tasks
- MongoDB database integration

## Tech Stack
- Node.js
- Express.js
- MongoDB
- Mongoose

## API Endpoints

GET /tasks → fetch all tasks  
POST /tasks → add task  
DELETE /tasks/:id → delete task  

## Setup

npm install  
node server.js
